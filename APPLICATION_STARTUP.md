## 📝 QUICK START COMMANDS

```bash
# Display bike information
npm run cli bike-info --spec

# List all tuning profiles
npm run cli tuning --list

# Apply SPORT profile (recommended)
npm run cli tuning --preset SPORT --apply

# Show current tuning status
npm run cli tuning --status

# Enable Smart System
npm run cli smart-system --enable

# Analyze your ride
npm run cli smart-system --analyze

# Get AI recommendations
npm run cli smart-system --recommend

# Show ML models
npm run cli smart-system --models

# Monitor in real-time
npm run cli smart-system --monitor --live

# Show statistics
npm run cli smart-system --statistics
```
