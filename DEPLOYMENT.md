## 🎯 GETTING STARTED

### For Users
```bash
# 1. Start the application
npm start

# 2. Get bike info
npm run cli bike-info --spec

# 3. List tuning profiles
npm run cli tuning --list

# 4. Apply SPORT profile (recommended)
npm run cli tuning --preset SPORT --apply

# 5. Enable Smart System
npm run cli smart-system --enable

# 6. Start monitoring
npm run cli smart-system --monitor --live
```

### For Developers
```bash
# 1. Install dependencies
npm install

# 2. Build TypeScript
npm run build

# 3. Run tests
npm run test

# 4. Start in development
npm run dev

# 5. Lint code
npm run lint
```
