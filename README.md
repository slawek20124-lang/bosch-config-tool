# Bosch Configuration Tool - Offline Ready

## 🌟 Features

- 🧠 Smart System AI (Offline)
- ⚙️ Motor Generation Support (Bosch Performance CX Gen 4)
- 🔋 Battery Management
- 🌎 Works Completely Offline
- 💾 No Internet Required
- ⚡ Performance Tuning

## 📊 Installation

```bash
npm install
```

## 🚀 Usage

### CLI Mode
```bash
npm run cli motor --info
npm run cli smart --enable
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
npm start
```
