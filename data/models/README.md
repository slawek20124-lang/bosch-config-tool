# Smart System Pre-trained Models

## Models

1. **energy_consumption** (92.5% accuracy)
   - Predicts energy consumption based on riding parameters
   - Features: speed, cadence, elevation, temperature

2. **range_prediction** (88.7% accuracy)
   - Predicts remaining range
   - Features: battery, speed, terrain, weather

3. **riding_style** (94.2% accuracy)
   - Detects riding style (Casual/Sport/Aggressive/Efficient)
   - Features: power, speed, cadence, acceleration

4. **assist_level** (91.3% accuracy)
   - Recommends optimal assist level
   - Features: slope, speed, battery, style
