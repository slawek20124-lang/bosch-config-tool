## ⚙️ KONFIGURACJA POCZĄTKOWA {#start}

### Step 1: Inspekcja Roweru

```bash
# Checklist przed pierwszą jazdą:

☑ Ogólna Bezpieczność:
  ✓ Sprawdź hamulce (czułość, modulacja)
  ✓ Sprawdź przerzutnik (płynne przejścia)
  ✓ Sprawdź opony (ciśnienie, bieżnik)
  ✓ Sprawdź zawieszenie (swoboda ruchu)
  ✓ Sprawdź siodło (wysokość, położenie)
  ✓ Sprawdź kierownicę (wyrównienie, swoboda)

☑ Elektrotechniczne:
  ✓ Sprawdź baterię (pełny ładunek)
  ✓ Sprawdź wyświetlacz (działanie)
  ✓ Sprawdź motor (bez dźwięków anomalnych)
  ✓ Sprawdź czujniki (działanie)
  ✓ Sprawdź kable USB (prawidłowe podłączenia)
```

### Step 2: Ustawienie Wysokości Siodła

```
Metoda 1 - Zasada "inseam":
  1. Stań nad ramą w naturalnej postawie
  2. Między noginami a ramą powinno być 5-10cm
  3. To określa przybliżoną wysokość siodła

Metoda 2 - Kąt kolana:
  1. Usadź się na siodełku
  2. Pedał w najniższym punkcie
  3. Kąt w kolanie powinien być ~25-30 stopni
  4. Pięta ma być na pedału bez zgięcia nogi

Metoda 3 - Pomiar:
  1. Stań z nogą na pedału (na dole)
  2. Noga powinna być prawie wyprostowana
  3. Niewielkie zgięcie w kolanie
```

### Step 3: Ustawienie Kierownicy

```
Horizontalna pozycja:
  - Powinno być wyrównane z przednią osią koła
  - Nie powinno być skręcone
  - Sprawdź wyrównanie z ramą

Wysolność kierownicy:
  - Powinna być na poziomie siodła lub niżej
  - W zależności od stylu jazdy
  - Agresywny styl = niżej
  - Confortable styl = wyżej
```

### Step 4: Zawieszenie - Wstępna Konfiguracja

```
Zawieszenie Przód (RockShox Yari RC):
  Sag Target:            25-30%
  Jak zmierzyć:
    1. W pełnym ekwipunku (jak normalnie jeździsz)
    2. Stań na rowerzе normalnie
    3. Zmierz dystans od górki łamy do siodła
    4. Zmierz to samo gdy siedzisz
    5. Różnica = sag
    6. Powinno być 25-30% całego travel (35-42mm)

  Rebound:               Start na "2 clicks from full open"
  Compression:           Start na "3 clicks from full open"

Zawieszenie Tył (Cube AMS 140mm):
  Sag Target:            25-30% (35-42mm)
  Air Pressure:          Zamieszenie tlenu zależy od wagi
                         Zacznij od 100 psi, dostosuj ±10 psi
  Rebound:               Start na "2 clicks from full open"
  Compression:           Start na "3 clicks from full open"
```

## 🆘 TROUBLESHOOTING {#troubleshooting}

### Problem: Motor nie włącza się

```
Diagnostyka:
  1. Sprawdź poziom naładowania baterii
     npm run cli battery --status
  
  2. Sprawdź połączenie (USB/Bluetooth)
     npm run cli detect --verbose
  
  3. Sprawdź czujniki
     npm run cli sensors --test
  
  4. Reset motor
     npm run cli motor --reset

Rozwiązania:
  ☐ Naładuj baterię w pełni (do 100%)
  ☐ Sprawdź kabel USB (czy nie uszkodzony)
  ☐ Restart wyświetlacza (OFF/ON)
  ☐ Kontakt serwis (jeśli trwa)
```

### Problem: Niska wydajność motoru

```
Diagnostyka:
  1. Sprawdź profil tuningu
     npm run cli tuning --status
  
  2. Analizuj jazdę
     npm run cli smart-system --analyze
  
  3. Sprawdź temperaturę
     npm run cli motor --temperature
  
  4. Test wydajności
     npm run cli motor --test --power

Rozwiązania:
  ☐ Zmień profil na SPORT/TURBO
  ☐ Sprawdź AI rekomendacje
  ☐ Pozwól motorowi ostudzić się (jeśli gorący)
  ☐ Zresetuj konfigurację
  ☐ Update firmware (jeśli dostępny)
```

### Problem: Szybkie drażnienie baterii

```
Diagnostyka:
  1. Analizuj zużycie energii
     npm run cli smart-system --analyze
  
  2. Sprawdź profil
     npm run cli tuning --status
  
  3. Oblicz spodziewany zasięg
     npm run cli battery --predict-range
  
  4. Porównaj z normą
     npm run cli battery --compare

Rozwiązania:
  ☐ Zmień na profil ECO/TOUR
  ☐ Redukcja agresywnego stylu jazdy
  ☐ Zwiększ opór opon (lepszą toczność)
  ☐ Zmniejsz tempo
  ☐ Rozważ większą baterię (625Wh lub 750Wh)
```

### Problem: Błędy Smart System

```
Diagnostyka:
  1. Sprawdź status AI
     npm run cli smart-system --status
  
  2. Zweryfikuj modele ML
     npm run cli smart-system --models --verify
  
  3. Czyszczenie cache
     npm run cli smart-system --clear-cache
  
  4. Restart systemu
     npm run cli smart-system --restart

Rozwiązania:
  ☐ Wyłącz i włącz Smart System
  ☐ Wyczyść cache danych
  ☐ Resetuj ML modele
  ☐ Załaduj świeże dane
  ☐ Restart aplikacji
```
